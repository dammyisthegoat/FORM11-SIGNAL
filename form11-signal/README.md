# FORM11 SIGNAL

A warm editorial business intelligence dashboard concept by **FORM11 TECH STUDIOS**.

## Run locally

Open `index.html` in a modern browser. No build step, package installation, account, API key, or backend is required.

## Publish on GitHub Pages

1. Create a repository and add `index.html`, `styles.css`, `app.js`, and this README at the repository root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your default branch and `/ (root)`, then save.

## Included

- Overview, revenue analytics, orders, customers, products, reports, and settings.
- Responsive sidebar navigation and layouts for desktop, tablet, and mobile.
- Interactive revenue chart with hover/focus tooltips and selectable 7-day, 30-day, 90-day, and 12-month periods.
- Search and status/segment/stock filters for the relevant tables.
- Local CSV downloads for sample orders, customers, products, revenue, and overview snapshots.
- Browser-local settings and interface notifications.
- No backend, paid integrations, or third-party JavaScript libraries.

## Important note on data

SIGNAL is a fictional product concept. All business names, sample customers, transactions, measurements, metrics, and insights are illustrative and do not represent a real business or live data connection. The demo uses USD display values by default.
